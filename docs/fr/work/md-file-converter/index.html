The MD File Converter

N'importe quel fichier en entrée, du Markdown propre en sortie, prêt pour l'IA. Un livre est passé de 359 528 tokens à 285 245.

Dans cette étudeCe que j'ai fait Le résultat
Outils
Python, FastAPI, pandas, JavaScript, pytest
En parler

Le problème

Les outils d'IA comptent en tokens tout ce que vous leur donnez, et ils ne peuvent en garder qu'un certain nombre à la fois. Un PDF, une page web ou un livre numérique transporte de la mise en page, du style et du balisage dont le modèle n'a pas besoin. Vous payez pour tout cela, à chaque message. Certains fichiers, le modèle ne peut pas les ouvrir du tout.

Ce que j'ai fait

C'est mon propre outil. Je l'ai fait pour que n'importe quel fichier entre dans une conversation avec une IA sous forme de Markdown propre : les mots et leur structure, rien d'autre. Je lui ai fixé trois règles : il fonctionne hors ligne, il tient sur un écran, et il ne refuse jamais un fichier.

Le corpus de test est fait de fichiers difficiles : un PDF scanné, un fichier à la mauvaise extension, un fichier vide, une base de données.

Comment ça marche

Une application locale : un serveur Python et FastAPI sur la machine, et une page dans le navigateur. Chaque fichier passe par les trois mêmes étapes.

  1. Identifier. L'application ne se fie jamais à l'extension. Elle lit les premiers octets, ouvre les conteneurs et détermine ce qu'est vraiment le fichier.
  2. Convertir. Chaque type de fichier a une chaîne ordonnée de moteurs. Le premier qui renvoie du contenu l'emporte. Si tous échouent, un moteur de secours renvoie quand même une fiche décrivant le fichier.
  3. Nettoyer. Douze passes nettoient le résultat brut : césures, retours à la ligne, niveaux de titres, tableaux, listes, liens, puis un en-tête qui dit d'où vient le texte.

Le résultat

Je l'ai mesuré sur un livre, Moby-Dick. En page web, il fait 359 528 tokens. Dans le Markdown que cet outil en a tiré, 285 245 tokens. Cela fait 74 283 tokens économisés, environ 21 %, chaque fois que le livre est envoyé à un modèle. À partir du fichier de livre numérique, l'économie est d'environ 24 %. La même fenêtre de contexte contient désormais davantage de vos documents. C'est une application de bureau qui fonctionne, avec 260 tests derrière elle.
