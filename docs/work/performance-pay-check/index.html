Talk to me about this

The problem

Pay follows the rating. When the rating and the compensation file disagreed, it usually surfaced at calibration, when it is expensive to fix.

What I did

I built the campaign dashboard and the daily check, and wrote the user guide.

Join on employee ID, flag the difference, let a person correct it.

How it works

A three-page dashboard tracks completion and shows every open form with the step it is stuck on.

  1. A three-page dashboard: completion by division and level, the list of open forms with their current step so managers can be chased by name, and completed forms with final ratings, exportable to Excel.
  2. A scheduled job joins appraisals to the compensation file on employee ID and emails each owner only the mismatches, and only when there are some.
