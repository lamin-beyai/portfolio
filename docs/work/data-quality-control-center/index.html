HR data-quality control center

91+ checks across 500+ employee records. About 20 hours of manual reconciliation removed each week, by my estimate.

Tools
Python, Polars, DuckDB, FastAPI, SQLite, Parquet, SAP SuccessFactors EC
Talk to me about this

The problem

Every week, someone rebuilt the same HR workbook by hand, and errors still reached payroll, contracts and work permits.

What I did

I proposed replacing it. Nobody asked me to. Then I designed it and built it.

How it works

A Python system with a FastAPI backend and a dashboard in the browser. Polars loads the files and DuckDB runs the checks that cross them.

  1. SuccessFactors extracts land in a folder. The engine checks each file's schema and row count, loads them with Polars and runs cross-file checks in DuckDB.
  2. Each control scores PASS, REVIEW or FAIL. A routing table sends every team only the rows it owns, so the result is a work queue, not a report.
  3. Every run is archived with its inputs, rule version, results and logs.
