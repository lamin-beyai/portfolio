Talk to me about this

The problem

Finance budgets on headcount. The answer sat in three HR files, each with its own date format.

What I did

I built the forecast from those three files, for recruitment and finance.

How it works

A monthly bridge. Start from opening headcount, take out departures and contract ends, add signed starts and moves.

  1. Start from the opening population by division and contract. Remove confirmed departures and fixed-term end dates, move confirmed internal mobilities, add signed starts.
  2. Open positions are shown apart, never assumed filled. Interns and fixed-term contracts are modelled explicitly, not averaged away.

The query behind this view
SELECT cause, COUNT(*) AS records, SUM(effect) AS change
FROM movements
WHERE month <= 12 AND department = 'eng'
GROUP BY cause
ORDER BY records DESC;
